# 🛍️ Web-Ларёк

Web-Ларёк - интернет-магазин с товарами для веб-разработчиков.

Пользователь может:

- просматривать каталог товаров;
- открывать подробную информацию о товаре;
- добавлять товары в корзину;
- удалять товары из корзины;
- выбирать способ оплаты;
- указывать адрес доставки;
- вводить контактные данные;
- оформлять заказ;
- получать уведомление об успешном оформлении заказа.

# 🏗 Архитектура

Приложение построено на разделении данных, представления и логики взаимодействия.

За хранение состояния отвечают модели:

* ProductModel - каталог и выбранный товар;
* CartModel - состояние корзины;
* BuyerModel - данные покупателя и их валидация.

Компоненты View отвечают за отображение интерфейса и генерируют события при действиях пользователя.

main.ts связывает модели и представления, обрабатывает события и управляет основными сценариями приложения.

Для коммуникации между компонентами используется EventEmitter.

Общая схема:
```text
                 ┌─────────────┐
                 │   Server    │
                 └──────┬──────┘
                        │
                        ▼
                 ┌─────────────┐
                 │ WebLarekApi │
                 └──────┬──────┘
                        │
                        ▼
              ┌──────────────────┐
              │      Models      │
              │                  │
              │ ProductModel     │
              │ CartModel        │
              │ BuyerModel       │
              └────────┬─────────┘
                       │
                       │ EventEmitter
                       ▼
              ┌──────────────────┐
              │       View       │
              │                  │
              │ Header           │
              │ Gallery          │
              │ Cards            │
              │ Basket           │
              │ Forms            │
              │ Modal / Success  │
              └──────────────────┘
```
# ⚙️ Базовые компоненты

## Component

Базовый класс для UI-компонентов.

Основные возможности:

* хранение корневого DOM-элемента;
* отображение данных через render();
* установка изображений через setImage().
```ts
render(data?: Partial<T>): HTMLElement
```
## Api

Базовый класс для HTTP-запросов.
```ts
Поддерживает:
get<T>(uri: string): Promise<T>
и
post<T>(
    uri: string,
    data: object,
    method?: ApiPostMethods
): Promise<T>
```
Также обрабатывает ответы сервера и ошибки запросов.

## EventEmitter

Брокер событий, реализующий событийное взаимодействие компонентов.

Основные методы:
```ts
on(event, callback)
emit(event, data?)
trigger(event, context?)
```
Используется для связи моделей и представлений без прямой зависимости компонентов друг от друга.

# 📊 Модели

## ProductModel

Хранит каталог товаров и выбранный товар.

Основные методы:
```ts
setProducts(products)
getProducts()
getProduct(id)
setPreview(product)
getPreview()
```
## CartModel

Управляет товарами в корзине.

Основные методы:
```ts
getItems()
add(product)
remove(product)
clear()
getTotal()
getCount()
hasProduct(id)
```
При изменении корзины модель генерирует событие cart:changed.

## BuyerModel

Хранит данные покупателя:
- payment
- email
- phone
- address

Основные методы:
```ts
setData(data)
getData()
clear()
validate()
```
Модель самостоятельно проверяет заполнение данных и возвращает ошибки валидации.

# 🌐 API

## WebLarekApi

Специализированный слой для работы с API магазина.

Получение каталога:
`GET /product/`
Создание заказа:
`POST /order/`
Методы:
```ts
getProducts()
createOrder(data)
```
# 🖥 View

## Header

Отображает шапку сайта и количество товаров в корзине.

Событие:
```ts
basket:open
```
## Gallery

Отображает каталог товаров.

Карточки каталога передаются через:
```ts
gallery.catalog = cards
```
## Card

Базовый класс карточки товара.

От него наследуются:

* CatalogCard
* PreviewCard
* BasketCard

Общие данные:

* название;
* цена.

## CatalogCard

Отображает товар в каталоге.

При выборе товара генерирует:
```ts
card:select
```
## PreviewCard

Отображает подробную информацию о товаре.

Содержит описание и кнопку покупки.

Событие:
```ts
card:buy
```
## Basket

Отображает содержимое корзины, общую стоимость и кнопку оформления заказа.

Основные данные:
* items
* total

## BasketCard

Отображает отдельный товар в корзине.

При удалении генерирует событие:
```ts
basket:remove
```
## Modal

Управляет модальным окном:
```ts
open(content)
close()
```
При закрытии генерирует:
```ts
modal:close
```
# 👔 Формы

## Form

Базовый класс для форм.

От него наследуются:

* OrderForm
* ContactsForm

Общие возможности:
* valid
* errors

## OrderForm

Первый этап оформления заказа.

Пользователь:

1. выбирает способ оплаты;
2. вводит адрес доставки.

События:
```ts
payment:change
order:change
order:submit
```
## ContactsForm

Второй этап оформления заказа.

Пользователь вводит:

* email;
* телефон.

События:
```ts
contacts:change
contacts:submit
```
## Success

Отображает результат успешного оформления заказа.

Показывает сумму списанных средств.

Событие закрытия:
```ts
success:close
```
# 📍 Основные события

## Событие - Назначение

`products:changed` - Обновление каталога

`card:select` - Выбор товара

`preview:changed` - Открытие подробной информации

`card:buy` - Добавление товара в корзину

`basket:open` - Открытие корзины

`basket:render` - Отрисовка корзины

`basket:remove` - Удаление товара

`cart:changed` - Изменение корзины

`payment:change` - Изменение способа оплаты

`order:change` - Изменение адреса

`order:render` - Открытие формы заказа

`order:valid` - Обновление валидации заказа

`order:submit` - Переход к контактным данным

`contacts:open` - Открытие формы контактов

`contacts:change` - Изменение контактных данных

`contacts:valid` - Обновление валидации контактов

`contacts:submit` - Отправка контактных данных

`order:send` - Отправка заказа на сервер

`order:success` - Успешное оформление заказа

`success:close` - Закрытие окна успеха

`modal:close` - Закрытие модального окна

`header:counter` - Обновление счётчика корзины

`buyer:changed` - Изменение данных покупателя

# 🔄 Основной сценарий

## Загрузка каталога
```text
Server
  ↓
WebLarekApi
  ↓
ProductModel
  ↓
products:changed
  ↓
Gallery
  ↓
CatalogCard
```
## Покупка товара
```text
CatalogCard
  ↓
card:select
  ↓
ProductModel
  ↓
PreviewCard
  ↓
card:buy
  ↓
CartModel
```
## Оформление заказа
```text
Basket
  ↓
OrderForm
  ↓
ContactsForm
  ↓
BuyerModel
  ↓
WebLarekApi
  ↓
POST /order/
  ↓
Success
```
## После успешного заказа
```text
Успешный ответ сервера
        ↓
CartModel.clear()
        ↓
BuyerModel.clear()
        ↓
Счётчик корзины = 0
        ↓
Окно успешного заказа
```
